# Lumen

Фоторедактор прямо в браузере, в стиле Apple: жидкое стекло, пружинные анимации, линейка‑«крутилка» как в приложении «Фото» на iPhone. Один HTML‑файл, без сборки и зависимостей — вся цветокоррекция считается на GPU через WebGL.

## Запуск

Просто откройте [`index.html`](index.html) двойным кликом в Chrome или Edge — файл самодостаточный, ничего скачивать не нужно.

Либо клонируйте репозиторий и откройте локально:

```bash
git clone https://github.com/Arbuzyakaby/lumen-photo-editor.git
cd lumen-photo-editor
```

и откройте `index.html`. Для разработки исходники разложены отдельно в [`css/`](css) и [`js/`](js) — см. раздел «Устройство» ниже; сам `index.html` — уже собранная из них версия, готовая к использованию как есть.

## Возможности

- **18 настроек**: экспозиция, блеск, света, тени, контраст, яркость, точка чёрного, насыщенность, сочность, теплота, оттенок, тон цвета, резкость, чёткость, выцветание, виньетка, зерно, размытие. Кнопка «Авто» анализирует гистограмму кадра и сама подбирает значения.
- **14 фильтров** с регулировкой интенсивности, плюс **свои пресеты** — сохраняются в `localStorage`, удаляются с возможностью «Вернуть».
- **Кадр**: поворот, отражение, стандартные пропорции, выпрямление ±45° без чёрных углов по краям.
- **Экспорт**: JPEG / PNG / WebP, качество, размер (оригинал, 4K, 2.5K, Full HD, для соцсетей), рамки (белая, чёрная, полароид), оценка веса файла, копирование в буфер обмена и «Поделиться».
- Гистограмма, сравнение с оригиналом (удерживать фото или пробел), история отмены/повтора, перетаскивание и вставка фото из буфера обмена.
- Два встроенных тестовых снимка — «День у озера» и «Ночь у озера», нарисованные прямо в коде на `<canvas>`.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Ctrl Z` / `Ctrl ⇧ Z` | Отменить / повторить |
| `Пробел` (удерживать) | Показать оригинал |
| `Ctrl O` | Открыть фото |
| `Ctrl S` | Экспорт |
| `H` | Гистограмма |
| `1` `2` `3` | Настройки / Фильтры / Кадр |
| Двойной клик по линейке настройки | Сбросить значение |

## Устройство

- [`js/engine.js`](js/engine.js) — рендер: геометрия, поворот/кадрирование и размытие на Canvas 2D, вся цветокоррекция — в одном WebGL‑шейдере.
- [`js/app.js`](js/app.js) — интерфейс, история изменений, пресеты, экспорт.
- [`js/scenes.js`](js/scenes.js) — процедурно нарисованные тестовые фото.
- [`css/style.css`](css/style.css) — стили «жидкого стекла».
- [`index.html`](index.html) — собранная версия: та же разметка плюс содержимое трёх файлов выше, инлайненное в `<style>`/`<script>`, чтобы файл работал при открытии прямо с диска.

Если правите исходники в `css/`/`js/`, пересоберите `index.html` вручную (замените содержимое соответствующих `<style>`/`<script>` блоков) или через любой скрипт, который подставляет файлы **функцией**‑заменителем, а не строкой — иначе `$$` в коде будет искажён спецсимволами подстановки `String.replace()`.

## Совместимость

Лучше всего работает в свежих Chrome и Edge (нужен WebGL). В Safari часть CSS‑эффектов (`backdrop-filter`) корректно работает начиная с 18‑й версии.
