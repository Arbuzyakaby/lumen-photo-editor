# Lumen

Фоторедактор в браузере в стиле Apple: жидкое стекло, пружинные анимации, линейка‑«крутилка» как в «Фото» на iPhone. Без сборки и зависимостей.

## Запуск

Нужен любой статический сервер (из `file://` браузер не даст загрузить скрипты по относительным путям в некоторых окружениях):

```bash
python -m http.server 8000
```

и открыть http://localhost:8000.

## Возможности

- **18 настроек**: экспозиция, блеск, света, тени, контраст, яркость, точка чёрного, насыщенность, сочность, теплота, оттенок, тон цвета, резкость, чёткость, выцветание, виньетка, зерно, размытие. Кнопка «Авто» анализирует гистограмму и подбирает значения.
- **14 фильтров** с регулировкой интенсивности, плюс **свои пресеты** (хранятся в `localStorage`, удаляются с возможностью «Вернуть»).
- **Кадр**: поворот, отражение, пропорции, выпрямление ±45° без чёрных углов.
- **Экспорт**: JPEG / PNG / WebP, качество, размер (оригинал, 4K, 2.5K, Full HD, соцсети), рамки (белая, чёрная, полароид), оценка размера файла, копирование в буфер и «Поделиться».
- Гистограмма, сравнение с оригиналом (удерживать фото или пробел), история действий, перетаскивание и вставка фото из буфера.
- Два встроенных примера: «День у озера» и «Ночь у озера».

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Ctrl Z` / `Ctrl ⇧ Z` | Отменить / повторить |
| `Пробел` (удерживать) | Показать оригинал |
| `Ctrl O` | Открыть фото |
| `Ctrl S` | Экспорт |
| `H` | Гистограмма |
| `1` `2` `3` | Настройки / Фильтры / Кадр |
| Двойной клик по линейке | Сбросить значение |

## Устройство

- `js/engine.js` — рендер: геометрия и размытие на Canvas 2D, вся цветокоррекция в одном WebGL‑шейдере.
- `js/app.js` — интерфейс, история, пресеты, экспорт.
- `js/scenes.js` — процедурно нарисованные тестовые фото.
- `css/style.css` — стили «жидкого стекла».
