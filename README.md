# Lumen

Фоторедактор прямо в браузере, в стиле Apple: жидкое стекло, пружинные анимации, линейка‑«крутилка» как в приложении «Фото» на iPhone. Один HTML‑файл, без сборки и зависимостей — вся цветокоррекция считается на GPU через WebGL, а снимки никуда не уходят из браузера.

**👉 [Открыть онлайн](https://arbuzyakaby.github.io/lumen-photo-editor/)** — GitHub Pages, обновляется автоматически при пуше в `main`.

## Запуск

Просто откройте [`index.html`](index.html) двойным кликом в Chrome или Edge — файл самодостаточный, ничего скачивать не нужно.

Либо клонируйте репозиторий и откройте локально:

```bash
git clone https://github.com/Arbuzyakaby/lumen-photo-editor.git
cd lumen-photo-editor
```

и откройте `index.html`. Для разработки исходники разложены отдельно в [`css/`](css) и [`js/`](js) — см. раздел «Устройство» ниже; сам `index.html` — уже собранная из них версия, готовая к использованию как есть.

## Возможности

### Обработка

- **18 настроек**: экспозиция, блеск, света, тени, контраст, яркость, точка чёрного, насыщенность, сочность, теплота, оттенок, тон цвета, резкость, чёткость, выцветание, виньетка, зерно, размытие. Кнопка «Авто» анализирует гистограмму кадра и сама подбирает значения.
- **14 фильтров** с регулировкой интенсивности, плюс **свои пресеты** — сохраняются в `localStorage`, удаляются с возможностью «Вернуть».
- **Рисование**: кисть, фломастер и ластик с настройкой цвета (тон/насыщенность/яркость или пипетка), толщины и мягкости края. Свои пресеты кистей сохраняются в `localStorage`. Штрихи входят в историю отмены и попадают в экспорт.
- **Кадр**: поворот, отражение, стандартные пропорции, выпрямление ±45° без чёрных углов по краям.
- **Умная обрезка** (`C`): строит карту деталей кадра — локальный контраст, цвет и свет — и сдвигает рамку туда, где сосредоточено главное. Если выбраны «Исходные», сама подбирает и пропорции: берёт те, у которых кадр получается самым насыщенным по содержанию, но не даёт отрезать полкадра ради мелкой выгоды. Рамка переезжает плавно, результат откатывается одной кнопкой.
- **Зум**: колесо мыши приближает к точке под курсором, перетаскивание двигает кадр, двойной клик — 200% и обратно. Клавиши `+`, `−`, `0` и панелька в углу снимка. Это просмотр, а не правка: на экспорт зум не влияет.
- **Игральный кубик 🎲** — бросок трёхмерного кубика случайно перемешивает характеристики кадра и плавно к ним переезжает. Сколько настроек затрагивает один бросок (от 3 до 14) задаётся в настройках приложения, а результат откатывается одной кнопкой в уведомлении.
- **Экспорт**: JPEG / PNG / WebP, качество, размер (оригинал, 4K, 2.5K, Full HD, для соцсетей), рамки (белая, чёрная, полароид), оценка веса файла, копирование в буфер обмена и «Поделиться».

### Что показывает про кадр

- **Графики и диаграммы** (кнопка со столбиками или `G`) — шесть визуализаций текущего вида со всеми правками, фильтром и штрихами: гистограмма RGB, накопленная тоновая кривая, кольцо распределения оттенков, радар профиля настроек, столбики изменённых настроек и волновая форма по столбцам кадра. Все они рисуются с анимацией появления.
- **Об изображении** (`I`) — исходное разрешение, мегапиксели, пропорции, размер кадра после кадрирования, число штрихов и изменённых настроек, а также измеренные средняя яркость, контраст, насыщенность, доля нейтральных тонов, провалы в тень и пересветы — с полосками‑индикаторами и палитрой основных цветов снимка.
- Быстрая **гистограмма** поверх фото (`H`) и сравнение с оригиналом — удерживайте снимок или пробел.

### Интерфейс

- **Три темы**: светлая, тёмная и системная (следует за оформлением ОС и переключается на лету, если сменить его в системе). Кнопка в верхней панели или `T` перебирает их по кругу, выбор запоминается. Весь цвет описан токенами, поэтому тему держит и интерфейс, и все окна; шкалы — гистограмма, графики, превью экспорта — остаются на тёмной подложке в обеих темах, как в профессиональных редакторах.
- **Верхняя панель** собрана из трёх групп: история (отмена, повтор, сброс), просмотр (сравнение, гистограмма, графики, инфо) и оформление (кубик, тема). Справа — «Открыть» и «Экспорт», слева — логотип с именем файла и меню примеров.
- **Настройки приложения** (`,` или меню под логотипом): тема, акцентный цвет из пяти вариантов, фоновое свечение, анимации, подсказки, качество предпросмотра (1200 / 1800 / 2400 px), размах кубика, показ уголка с рекомендацией, повторный запуск обучения и очистка всего сохранённого.
- **«О проекте»** — из чего собран редактор, счётчики возможностей и ссылки на исходники, сайт и второй проект автора.
- **Анимированное обучение** при первом входе: подсвечивает по очереди панель сверху, фото, док с вкладками, кубик, графики и экспорт. Показывается один раз, повторить можно из настроек.
- Гистограмма, история отмены/повтора, перетаскивание и вставка фото из буфера обмена, уголок с рекомендацией второго проекта — [RuPolitCompass](https://rupolitcompass.website) — который скрывается одной кнопкой.
- **Меню** под шестерёнкой в верхней панели: настройки приложения, повтор обучения и «О проекте». Список примеров живёт отдельно — под логотипом.
- **Три шрифта**: «современный» (системный, как в macOS и Windows), «компактный» (узкий и плотный, больше влезает) и «творческий» (округлый). Меняется одна пара токенов, поэтому шрифт подхватывает весь интерфейс целиком.
- **Свой акцентный цвет** — рядом с пятью готовыми вариантами есть пипетка: цвет текста на кнопке экспорта подбирается автоматически, чтобы он оставался читаемым на любом фоне.
- Восемь встроенных тестовых снимков, нарисованных прямо в коде на `<canvas>`: «День у озера», «Ночь у озера», «Летний луг», «Полдень в дюнах», «Ночной город», «Северное сияние», «Берег океана» и «Туман в лесу». Последние два добавлены как крайние случаи: берег проверяет баланс белого и насыщенность, туман — контраст, чёткость и выцветание.

## Устройство

- [`js/engine.js`](js/engine.js) — рендер: геометрия, поворот/кадрирование и размытие на Canvas 2D, вся цветокоррекция — в одном WebGL‑шейдере.
- [`js/scenes.js`](js/scenes.js) — процедурно нарисованные тестовые фото. Каждая сцена рисуется в двойном размере и один раз уменьшается: при отрисовке один-к-одному мелкая даль (кромка леса, трава, блики на воде, окна домов) шириной в пиксель превращалась в рябь, стоило редактору её перемасштабировать.
- [`js/brush.js`](js/brush.js) — рисование: цветовая математика (HSV↔hex), хранение и отрисовка штрихов, пресеты кистей.
- [`js/analysis.js`](js/analysis.js) — статистика кадра (гистограммы, доминирующие цвета, волновая форма), карта деталей и поиск кадра для умной обрезки, бросок кубика и отрисовка всех диаграмм. Не обращается к DOM: получает готовый контекст канваса, поэтому целиком покрыт юнит‑тестами.
- [`js/app.js`](js/app.js) — интерфейс: история изменений, пресеты, экспорт, настройки, обучение.
- [`css/style.css`](css/style.css) — стили «жидкого стекла».
- [`index.html`](index.html) — собранная версия: та же разметка плюс содержимое файлов выше, инлайненное в `<style>`/`<script>`, чтобы файл работал при открытии прямо с диска (и чтобы GitHub Pages отдавал один файл без лишних запросов).

### Разработка

Правьте исходники в `css/` и `js/`, **не** `index.html` напрямую — он собирается автоматически:

```bash
npm run build   # пересобирает index.html из css/ и js/
npm test        # node:test — проверяет, что index.html не разошёлся с исходниками, плюс юнит‑тесты brush.js и analysis.js
```

`build.mjs` подставляет файлы в `<style>`/`<script>` блоки index.html **функцией**‑заменителем, а не строкой — иначе `$$` в коде был бы искажён спецсимволами подстановки `String.replace()`. Порядок блоков `<script>` в `index.html` должен совпадать с массивом `SCRIPTS` в `build.mjs`; если добавляете новый модуль — добавьте и пустой блок `<script></script>` в нужном месте. Один из тестов (`npm test`) как раз сверяет закоммиченный `index.html` с пересборкой из исходников — если забыть `npm run build`, тест упадёт.

## Что где хранится

Всё лежит только в `localStorage` этого браузера и стирается кнопкой «Очистить» в настройках:

| Ключ | Что |
| --- | --- |
| `lumen.presets` | свои пресеты фильтров |
| `lumen.brush`, `lumen.brushes` | текущая кисть и её пресеты |
| `lumen.settings` | тема, шрифт, акцент, качество предпросмотра, размах кубика |
| `lumen.export` | последние параметры экспорта |
| `lumen.hist` | включена ли гистограмма |
| `lumen.tour`, `lumen.promoHidden` | пройдено ли обучение, скрыт ли уголок |

## Деплой

Сайт публикуется через GitHub Pages прямо из ветки `main` (корень репозитория) — `index.html` уже самодостаточен, отдельный шаг сборки для Pages не нужен. Чтобы обновить сайт: `npm run build` → закоммитить → `git push` в `main`, через минуту‑две изменения появятся на https://arbuzyakaby.github.io/lumen-photo-editor/.

## Совместимость

Лучше всего работает в свежих Chrome и Edge (нужен WebGL). В Safari часть CSS‑эффектов (`backdrop-filter`) корректно работает начиная с 18‑й версии. Если WebGL недоступен, редактор честно предупреждает и продолжает работать без цветокоррекции.
